# Privacy Policy

Effective date: June 15, 2026.

PageMint Offline converts user-selected files into Markdown on the device running the
app. The PageMint project maintainers provide this privacy policy for the open-source
application.

## Information processed

PageMint Offline accesses files only when the user selects them for conversion. These
files may contain personal or sensitive information depending on what the user chooses.

## How files are used

Selected files are used to detect file format and generate Markdown output. The current
offline workflow does not require an account, advertising ID, analytics SDK, or cloud
upload.

## Retention

Uploaded files are stored in temporary app storage during conversion and deleted after
the conversion request finishes. Converted files are saved only when and where the user
chooses to download or export them.

## Sharing

The current offline workflow does not share user-selected files or converted content with
third parties.

## Changes

If analytics, crash reporting, ads, cloud conversion, sync, accounts, or remote URL
conversion are added later, this policy and the Google Play Data safety form must be
updated before release.

## Contact

Contact the project maintainers through the public GitHub repository. Security
vulnerabilities should be reported privately as described in `SECURITY.md`.
